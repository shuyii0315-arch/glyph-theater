# Glyph Theater

Tiny ASCII stories: a skill for Claude and other AI agents.

A character wants something, goes for it in its own way, something goes a little wrong, and it reacts. Give the skill a topic and it picks a classic ASCII character, writes four beats with real tension, and plays them as a looping scene in black and white with one accent color.

**Live page:** https://shuyii0315-arch.github.io/glyph-theater/

## Install

Give this to your agent:

```
Install the Glyph Theater skill for me.
1. Download https://shuyii0315-arch.github.io/glyph-theater/SKILL.md
2. Save it as glyph-theater/SKILL.md in this tool's skills folder:
   Claude Code: ~/.claude/skills/
   Codex: ~/.codex/skills/
   Cursor: ~/.cursor/skills/
   Other agents: .agents/skills/ in this project
3. Tell me where you saved it.
```

In the Claude app, upload `glyph-theater.zip` in your skill settings.
